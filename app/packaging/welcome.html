BHTerminal __VERSION__

A free SSH, SFTP and VNC client — the session tree, the terminal, the file browser and remote desktops in one window.

  • Your shell and your files in the same tab, on the same login.
  • Split a tab, and broadcast what you type to every pane in it.
  • Import your MobaXterm sessions, passwords included.
  • Passwords and key passphrases encrypted on this Mac, filled in for you.

This installer puts BHTerminal.app in your Applications folder. If an older copy is running it is quit first, and the new one opens when the install finishes.
