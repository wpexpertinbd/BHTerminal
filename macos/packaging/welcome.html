BHTerminal __VERSION__

A fast, native SSH · SFTP · VNC client for macOS — a free MobaXterm / Termius alternative.

This installer places BHTerminal in your Applications folder. It gives you:

  • A saved-session tree with folders — SSH, SFTP & VNC hosts
  • Real-ssh terminal: keys, agent, passphrase, 2FA & ProxyJump — tabs & split panes
  • Side-by-side SFTP file browser that shares the terminal's connection (no second login)
  • Port forwarding (local / remote / dynamic), broadcast input, snippets, session logging
  • Secrets kept in the macOS Keychain — never written to disk in plaintext
  • Import your saved hosts from MobaXterm & Termius
100% free & open-source — built with ❤️ by BiswasHost (Benjamin Biswas).
